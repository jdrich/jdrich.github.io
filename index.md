Technical change is happening faster than ever. New paradigms and conventions for defining software systems are being developed daily. The justification for technology - what makes it worth doing, what blocks it, what it costs and what it's worth - are changing constantly. The underlying needs aren't.

## Repositories

A few projects.

- [catmouse](https://github.com/jdrich/catmouse) Live prompt-injection eval harness. Air-gapped attacker/defender across eight threat levels; success is stated intent only.
- [sttttts](https://github.com/jdrich/sttttts) Local CPU-only STT/TTS server (Moonshine + Kokoro ONNX). Built to test speech for pi.dev plugins.
- [cohuatl](https://github.com/jdrich/cohuatl) A simple PHP framework.
- [pipio](https://github.com/jdrich/pipio) Evented interface for building scalable, service-oriented applications in PHP.
- [crier](https://github.com/jdrich/crier) An Event Emitter.
- [bangjs](https://github.com/jdrich/bangjs) JavaScript templating library.
